## 1. Огляд проєкту

Проєкт реалізує інтелектуального помічника спортивного щоденника для атлетів та тренерів. Асистент надає науково обґрунтовані рекомендації щодо тренувальних мікроциклів, розрахунку пульсових зон Карвонена, силових протоколів, гідратації та періодизації навантажень на основі верифікованої колекції з 10 документів (`doc-01`–`doc-10`).

У межах лабораторної роботи реалізовано повний життєвий цикл розробки агента:
- **Spec-First проєктування** та підготовка еталонного набору запитів (20 запитів із валідатором).
- **Ізольовані субагенти** з розподілом контексту та незалежний верифікатор як брама до злиття.
- **Гібридний пошук (BM25 + Semantic Embeddings + Reciprocal Rank Fusion)** із обов'язковим цитуванням першоджерел `[doc-XX]`.
- **Емпіричне оцінювання** порівняно з базовою лінією, аналіз помилок та паралелізація пулу субагентів із контролем бюджету.
- **Власний MCP-сервер** за специфікацією меж безпеки, протестований на відмову та інтегрований як з агентом кодування, так і з прикладним застосунком.

## 6. Інструкція відтворення з чистого клону

### 6.1. Клонування та встановлення залежностей
```bash
git clone https://github.com/Volodymyr-Is/AI-41-Agents-Project.git
cd AI-41-Agents-Project
npm ci
```

### 6.2. Прогін перевірок якості (Quality Gates)
Усі перевірки проходять локально в офлайн-режимі без зовнішніх платних викликів:
```bash
# 1. Запуск усіх 148 юніт- та інтеграційних тестів у Vitest
npm test

# 2. Перевірка статичної типізації TypeScript
npm run typecheck

# 3. Перевірка стилю коду та правил лінтера
npm run lint

# 4. Перевірка повної оптимізованої збірки Next.js
npm run build
```

### 6.3. Відтворення індексації та гібридного пошуку
```bash
# Побудова та серіалізація індексу корпусу (10 документів, 21 чанк)
npx tsx scripts/build-index.ts

# Гібридний пошук із детальним 3-колонковим поясненням RRF
npx tsx scripts/search.ts --query "норма споживання рідини" --explain
```

### 6.4. Запуск MCP-сервера та демонстрація підключень
```bash
# Прямий запуск MCP-сервера через stdio
npm run mcp:server

# Демонстрація виклику з боку агента кодування (створює trace у docs/lab2/traces/)
npm run mcp:agent-demo

# Демонстрація виклику з боку застосунку спортивного щоденника
npm run mcp:app-demo
```
