# [doc-06] Відновлення після інтенсивного навантаження

## 1. Сон — основа адаптації
Для атлетів під час інтенсивних тренувальних блоків тривалість якісного сну має становити не менше 8-9 годин на добу.

## 2. Відновлювальне вікно та живлення
- Протягом 30-45 хвилин після важкого або тривалого тренування рекомендовано вжити вуглеводи та легкозасвоюваний білок у співвідношенні 3:1 або 4:1 (для поповнення запасів глікогену та регенерації мікророзривів м'язових волокон).
- Легкий стретчинг та міофасціальний реліз (МФР на ролі) знижують гіпертонус м'язів.
