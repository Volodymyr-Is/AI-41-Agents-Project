# [doc-03] Протокол силового тренування для бігунів

## 1. Ціль силового тренінгу в бігу
- Зміцнення зв'язок і сухожиль, запобігання травмам коліна (IT-band, коліно бігуна).
- Покращення бігової економічності за рахунок зміцнення м'язів кору та сідниць.

## 2. Базовий комплекс вправ (2 рази на тиждень)
1. **Присідання на двох ногах / на одній нозі:** 3 підходи по 12 повторень.
2. **Випади назад або болгарські спліт-присідання:** 3 підходи по 10 повторень на кожну ногу.
3. **Сідничний місток:** 3 підходи по 15 повторень із фіксацією у верхній точці на 2 секунди.
4. **Підйоми на носки для литкових м'язів:** 3 підходи по 20 повторень.
5. **Планка (класична та бокова):** 3 підходи по 45-60 секунд.
