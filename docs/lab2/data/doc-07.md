# [doc-07] Ознаки перетренованості та методи діагностики

## 1. Симптоми синдрому перетренованості
- Хронічна втома та порушення сну (безсоння або надмірна сонливість).
- Підвищений пульс у спокої вранці (на 5-10 ударів/хв вище норми протягом кількох днів поспіль).
- Зниження імунітету (часті застуди).
- Падіння силових показників та бігового темпу при звичних зусиллях.

## 2. Що робити при виявленні
Зменшити обсяг та інтенсивність на 50% або взяти 3-7 днів повного відпочинку.
