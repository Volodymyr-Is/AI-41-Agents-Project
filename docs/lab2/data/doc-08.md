# [doc-08] Базові принципи розминки та заминки

## 1. Розминка перед бігом
- **Динамічна розтяжка:** Махи ногами, обертання тазом, випади на місці з розворотом корпусу.
- **Спеціальні бігові вправи (СБВ):** Біг із високим підніманням стегна, захльос гомілки, оленячий біг, прискорення на 50-60 метрів.
- *Статична розтяжка перед стартом не рекомендується*, оскільки вона тимчасово знижує пікову силу м'язів.

## 2. Заминка
- 5-10 хвилин повільного підтюпцем або кроком для виведення лактату та нормалізації частоти серцевих скорочень.
- М'який статичний стретчинг основних груп м'язів.
