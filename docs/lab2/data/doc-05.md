# [doc-05] Періодизація навантажень: мезоцикли та макроцикли

## 1. Ієрархія періодизації
- **Макроцикл:** Загальний план підготовки на сезон або 6-12 місяців (підготовка до цільового старту/марафону).
- **Мезоцикл:** Середній блок із 3-6 мікроциклів (тижнів), спрямований на розвиток конкретної якості (наприклад, базова витривалість, швидкісна витривалість, тейпер/підведення).
- **Мікроцикл:** Тижневий розклад окремих тренувальних занять.

## 2. Правило 10%
Щотижневий біговий обсяг не повинен збільшуватися більш ніж на 10% порівняно з попереднім тижнем, щоб запобігти стресовим травмам окістя та сухожиль.
