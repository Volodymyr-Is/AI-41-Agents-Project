# [doc-04] Гідратація та електроліти під час тривалих навантажень

## 1. Норми споживання рідини
- За 2 години до старту: 400-600 мл води.
- Під час тренування тривалістю понад 60 хвилин: 150-250 мл кожні 15-20 хвилин.
- При тренуваннях у спеку (понад 25°C) обов'язкове додавання електролітів (натрій, калій, магній).

## 2. Небезпека гіпонатріємії
Надмірне вживання чистої дистильованої води без солей може призвести до зниження концентрації натрію в крові (гіпонатріємії), що викликає судоми, нудоту та запаморочення.
