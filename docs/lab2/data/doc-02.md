# [doc-02] Розрахунок пульсових зон за формулою Карвонена

## 1. Формула резерву пульсу (HRR)
Формула Карвонена враховує пульс у спокої ($HR_{rest}$) та максимальний пульс ($HR_{max}$):
$$HR_{max} = 220 - \text{вік}$$
$$HRR = HR_{max} - HR_{rest}$$
$$\text{Цільовий пульс} = (HRR \times \% \text{інтенсивності}) + HR_{rest}$$

## 2. Пульсові зони
1. **Зона 1 (Відновлювальна):** 50-60% від HRR. Сприяє активному відновленню.
2. **Зона 2 (Аеробна / легкий біг):** 60-70% від HRR. Основна зона спалювання жирів та розвитку капілярної сітки.
3. **Зона 3 (Темпова):** 70-80% від HRR. Розвиток витривалості.
4. **Зона 4 (Анаеробний поріг / ПАНО):** 80-90% від HRR. Робота на межі закислення м'язів (лактат).
5. **Зона 5 (Максимальна):** 90-100% від HRR. Короткі спринти, інтервали до 1-2 хвилин.
