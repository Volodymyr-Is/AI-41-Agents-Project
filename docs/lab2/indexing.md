## 1. Стратегія чанкінгу (Chunking Strategy)

Для підготовки набору документів спортивної тематики (`doc-01` ... `doc-10`) реалізовано структурно-семантичний поділ тексту на фрагменти (чанки):

1. **Ієрархія заголовків:** Розбиття ведеться за заголовками Markdown другого рівня (`## `). Кожен розділ представляє окрему логічну тему (наприклад, «Пульсові зони», «Норми споживання рідини», «Симптоми перетренованості»).
2. **Розмір вікна та перекриття:**
   - Базовий максимальний розмір чанка: `maxChunkSize = 400` символів.
   - Мінімальний поріг: `minChunkSize = 50` символів (для відсікання порожніх службових рядків).
   - Перекриття (overlap): `overlap = 60` символів при вимушеному розбитті довгих абзаців, щоб зберегти контекст між сусідніми фрагментами.
3. **Збереження метаданих:** До кожного фрагмента прикріплюються метадані:
   - `id`: унікальний ідентифікатор у форматі `doc-XX#chunk-Y`;
   - `docId`: назва вихідного файлу (`doc-XX.md`);
   - `docTitle`: заголовок документа з першого рівня H1;
   - `sectionTitle`: назва відповідного підрозділу;
   - `tokenCount`: оцінка кількості токенів (~4 символи на токен).

## 3. Моделі представлення: BM25 та Векторний простір

Система реалізує повноцінне гібридне представлення даних:

### 3.1. Лексичний індекс BM25
- **Токенізація:** Нижній регістр, виділення слів українською та англійською мовами (`/[\p{L}\p{N}]+/gu`).
- **Стоп-слова:** Фільтрація загальних українських прийменників та сполучників (`і`, `в`, `на`, `з`, `за`, `до`, `як`, `та` тощо).
- **Параметри Okapi BM25:**
  - $k_1 = 1.5$ (насичення частоти терміна);
  - $b = 0.75$ (штраф за надлишкову довжину документа);
  - $IDF(q) = \ln\left(\frac{N - n(q) + 0.5}{n(q) + 0.5} + 1\right)$.

### 3.2. Векторний семантичний індекс
- **Розмірність:** 256-вимірний щільний вектор ознак.
- **Генерація ознак:** Хешування слів та символьних 3-грамів (subword semantic fingerprints) із нормалізацією вектора до одиничної довжини ($\|v\|_2 = 1.0$).
- **Метрика подібності:** Косинусна схожість (Cosine Similarity):
  $$\text{sim}(u, v) = \frac{u \cdot v}{\|u\| \|v\|}$$
