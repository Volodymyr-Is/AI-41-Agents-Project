# Специфікація: асистент по колекції документів

Автор: Ісаєнко Володимир Андрійович · Дата: 28.09.2026 · Версія: v1

## 1. Задача й користувач
Хто користувач: Спортсмени та тренери, які ведуть спортивний щоденник та хочуть аналізу пророблених чи запланованих вправ.
Яке питання він ставить і що робить із відповіддю: Як ефективно тренуватись, щоб досягти результату або підтримати спортивну форму?
Що він робить сьогодні без асистента: Шукає інформацію по конкретним технікам вправ в інтернеті, пише виконане в нотатки для майбутнього аналізу з тренером, лікарем чи ШІ.

## 4. Non-goals v1 (чого асистент НЕ робить)
- Асистент не ставить медичних  діагнозівта не призначає лікування.
- Асистент не замінює тренера чи лікаря, а є лише помічником.
- Асистент не надає інформацію, яка не міститься в документах.

## 5. Обсяг v1
Входить:
- Гібридний пошук (повнотекстовий + семантичний) по проіндексованих документах колекції `doc-01`...`doc-10`.
- Генерація відповідей із обов'язковим зазначенням цитованих джерел у форматі `[doc-XX]`.
- Пряма відмова при запитах з тегом `unanswerable`, якщо даних немає в документах.
- Стійкість до спроб prompt injection (`injection`).

Не входить до v1, але передбачено на майбутнє:
- Автоматична інтеграція зі Strava, Garmin Connect або іншими фітнес-сервісами.
- Мультимодальний аналіз техніки вправ за відео/зображеннями.
- Повноцінна багатокрокова діалогова пам'ять (v1 фокусується на Single-Turn пошуку з цитуванням).

## 6. Критерії приймання
Кожен — твердження, яке перевіряється командою, тестом або файлом із числом.

| # | Критерій (перевірне твердження) | Чим перевіряється |
|---|---|---|
| A1 | `npm test` зелений, зокрема тести валідатора еталонного набору | прогін CI |
| A2 | `docs/lab2/golden/queries.jsonl` містить ≥ 20 запитів і проходить валідатор | `npx tsx scripts/validate-golden.ts` |
| A3 | Базова лінія знята до реалізації пошуку і зафіксована у `baseline.md` | Перевірка історії комітів та `docs/lab2/baseline.md` |
| A4 | Гібридний пошук дає приріст точності порівняно з базовою лінією | `docs/lab2/eval-report.md` |
| A5 | Верифікатор на незалежній моделі блокує злиття PR за відсутності доказів | `docs/lab2/verifier.md` |
