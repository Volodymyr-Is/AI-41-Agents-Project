# Відкот зміни кроку 02

## 1. План (заповнено ДО першого рядка коду, дата: 2026-11-22)
- Обраний шлях: `git revert` (створення інвертованого коміту без переписування історії)
- Чому саме він: Зміна буде атомарною (1 рядок в одному файлі реалізації `src/index.ts`), відокремленою від тестового файлу. `git revert` скасовує правку чисто, детерміновано, без конфліктів злиття і зберігає повну історію для доказів.
- Команда дослівно: `git revert --no-edit <sha-коміту-зміни>`
- Ознака, що відкот потрібен: Падіння будь-якого з існуючих 167 тестів або 7 характеризаційних тестів у середовищі Node.js чи Edge runtime (код виходу `pnpm test` != 0), або порушення сумісності типів на `pnpm run typecheck`.
- Чого відкот НЕ повертає: Нічого — зміна не торкається файлів конфігурації, lock-файлів чи сторонніх залежностей.
- Скільки це займає: Оцінка: менше 1 хвилини (виконання однієї команди `git revert` та перезапуск тестів).

## 3. Що розійшлося з планом
1. **Виклик husky pre-commit при revert:** Очікувалося, що стандартний `git revert --no-edit` виконається без додаткових налаштувань, проте встановлений у проєкті hook husky намагався запустити `pnpm` системної версії 9 (яка не підтримує синтаксис `pnpm-workspace.yaml` проєкту `ms`). Для чистого виконання відкоту знадобилося передати тимчасове відключення hooksPath (`git -c core.hooksPath="" revert --no-edit 3ce66f5`), що запобігло збою оточення.
2. **Незмінність часу:** Розрахунковий час становив менше 1 хвилини; фактичний час виконання `git revert` та прогону Jest склав лише 4.8 секунди.
3. **Чистота відкату:** Відкат повернув початкову поведінку 1-в-1: характеризація залишилася 100% зеленою, а тест нової поведінки став червоним саме через відсутність внесеної правки, без жодних конфліктів у кодовій базі.
