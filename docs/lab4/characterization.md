## 3. Що свідомо НЕ покрито
| що | чому не покрито | чим це загрожує на кроці 02 |

| Граничні числа понад `Number.MAX_SAFE_INTEGER` ($> 2^{53}-1$) | Стандарт JavaScript IEEE-754 втрачає точність цілих чисел; бібліотека не використовує `BigInt` | Загрози немає: інтервали часу для практичних задач не перевищують сотні років |
