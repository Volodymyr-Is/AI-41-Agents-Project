# Таблиця переносності — Лабораторна 1

Порівняння поведінки двох агентів кодування (**Codex CLI** та **Antigravity CLI / IDE**) на однакових задачах проєкту.

| Категорія | Критерій / Що перевіряли | Codex CLI | Antigravity CLI / IDE | Висновок / Різниця |
|---|---|---|---|---|
| **Правила проєкту** | Читання `AGENTS.md` | Читає автоматично як системний контекст | Читає `AGENTS.md` з кореня | Обидва інструменти однаково сприймають правила без додаткових налаштувань. |
| **Журнал дій (Hooks)** | Налаштування перехоплення інструментів | `.codex/hooks.json` (подія `PostToolUse`) | `.agents/hooks.json` (подія `PostToolUse`) | Формати конфігурації схожі, але Antigravity виконує команду з CWD `.agents/` (потрібен `../` у шляху) та очікує `{}` у stdout. |
| **Режим плану (Plan)** | Дослідження коду без модифікацій | Режим plan у сесії, пропонує кроки перед diff | Дослідження безпосередньо у чаті/плані без запису | Обидва дозволяють верифікувати план до внесення змін у файлову систему. |

| **Автономність** | Дотримання меж безпеки | Не редагував `.env.local`, запитував підтвердження команд | Дотримувався заборон на редагування заборонених файлів | Рівень автономності контрольований (L1/L2). |

## Що довелося писати двічі

- **Конфігурація перехоплення подій (Hooks):** Налаштування хуків відрізняється між інструментами (`.codex/hooks.json` для Codex CLI та `.agents/hooks.json` для Antigravity). Проте сам обробник `scripts/agent-log-hook.mjs` є єдиним і універсальним.
- **Розташування та виявлення навичок (Skills):** Codex/Claude шукають навички у `.claude/skills/`, тоді як Antigravity сканує `.agents/skills/`. Синхронізація автоматизована за допомогою утиліти `scripts/sync-skills.ts`.
- **Конфігурація MCP-серверів:** Різні формати декларації зовнішніх серверів (TOML конфіг клієнта проти JSON схеми `.agents/mcp_config.json`).

## Примітки щодо сумісності

- **Журнал**: Універсальний скрипт `scripts/agent-log-hook.mjs` успішно обробляє події обох інструментів, зберігаючи єдиний 6-полюсний JSONL-формат.
- **Заборони та безпека**: Хук `scripts/guard-env.mjs` перехоплює файлові та командні операції до їх виконання, запобігаючи витоку секретів у публічні логи або репозиторій.
- **MCP**: Підключення Context7 додає ~450 токенів схем інструментів на кожен крок звернення до моделі (деталі у `docs/lab1/context-cost.md`).
- **Швидкість та якість**: Обидва агенти безпомилково реалізували спільні задачі після узгодження планів.
