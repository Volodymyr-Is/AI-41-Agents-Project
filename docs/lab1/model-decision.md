## Ризики і відкат

- **Дата зняття з підтримки (`retiresNotBefore`):** Модель `gemini-3.8-flash` гарантовано підтримується після 2026-10-01 (переживає захист лабораторної).
- **Політика даних безкоштовного рівня:** Дані безкоштовного API можуть використовуватися вендором для покращення моделей, тому через API пропускається виключно відкритий навчальний код без персональних даних або секретів.
- **Що погіршилося:** Для малонавантажених разових запитів без кешу затримка першого виклику незначно коливається залежно від доступності API.
- **За якої умови повернете попередню модель:** У разі жорстких обмежень квоти запитів (HTTP 429) на стороні Google AI Studio повернення до `gemini-2.5-flash` або перемикання на шлюз OpenRouter (`OPENROUTER_MODEL`).
- **Коміт зі зміною в src/models.ts:** `dc4729f` (оновлення ролей моделей та актуалізація цін).
