# Вступ (чернетка) · курсова робота

## Актуальність

Сучасний тренувальний процес як професійних спортсменів, так і аматорів фізичної культури вимагає регулярної фіксації навантажень, динаміки показників та системного аналізу ефективності виконаних програм. Традиційні спортивні щоденники та мобільні трекери здебільшого обмежуються пасивним збереженням статистичних даних або базовою візуалізацією графіків без надання глибокого контекстного зворотного зв'язку.

Розвиток сучасних систем автономних агентів на базі великих мовних моделей (LLM) відкриває нові можливості для інтелектуального аналізу спортивних результатів. Агентні системи здатні динамічно інтерпретувати тренувальні логи, виявляти ознаки перетренованості, балансувати обсяги навантажень та формувати адаптивні персоналізовані рекомендації, виконуючи роль цифрового асистента тренера з безпечним контролем доступу до персональних даних.

## Мета роботи

Розробка спортивного журналу з автономним агентним ШІ-асистентом для структурованого збереження тренувальних даних, багатокрокового аналізу прогресу та генерації персоналізованих рекомендацій щодо оптимізації фізичного навантаження.

## Завдання

1. Дослідити архітектурні патерни побудови автономних агентних систем (Tool Calling, Prompt Caching, драбина довіри, моніторинг трас OpenTelemetry).
2. Спроєктувати схеми даних для фіксації тренувальних сесій (вправи, підходи, вага, RPE, пульсові зони, самопочуття) з валідацією за допомогою Zod.
3. Реалізувати безпечний агентний контур на базі AI SDK та Langfuse для інтелектуального аналізу журналів навантаження зі строгими межами довіри (Human-in-the-loop).
4. Розробити вебзастосунок на стеку Next.js App Router та TypeScript із підтримкою інтерактивних звітів та рекомендацій ШІ.
5. Провести експериментальну оцінку ефективності, вартості та латентності агентних циклів на хмарних та локальних моделях.

## Об'єкт і предмет дослідження

- **Об'єкт дослідження:** Процес аналізу та оптимізації спортивних тренувальних даних за допомогою інтелектуальних систем.
- **Предмет дослідження:** Методи, алгоритми та архітектурні патерни агентної взаємодії (LLM Agent Loop, tool calling, prompt engineering) для аналізу спортивних журналів.

## Методи і технології

- **Мова програмування та середовище:** TypeScript (strict mode), Node.js.
- **Фреймворк:** Next.js (App Router, React Server Components).
- **Агентні фреймворки та інструменти:** AI SDK (`ai`), LLM Tool Calling, Prompt Caching, MCP (Model Context Protocol).
- **Валідація та тестування:** Zod, Vitest (юніт- та інтеграційні тести), Playwright (E2E-тестування інтерфейсу).
- **Телеметрія та спостережуваність:** OpenTelemetry, Langfuse Cloud.
- **Моделі:** Google Gemini (хмарна аналітика), Ollama / Qwen (локальна безпечна обробка).
