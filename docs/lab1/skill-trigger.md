# Тест на спрацювання навички (Skill Trigger) — Лабораторна 1

Перевірка коректності спрацювання та маршрутизації навички `add-api-route` на двох інструментах кодування (**Codex CLI** та **Antigravity CLI / IDE**).

## 1. Специфікація навички

- **Назва**: `add-api-route`
- **Розташування**: `.claude/skills/add-api-route/SKILL.md` та `.agents/skills/add-api-route/SKILL.md` (синхронізовано через `npm run sync-skills`).
- **Маршрутизація (description)**: «Додає API-маршрут у app/api цього проєкту: схема zod у src/, обробник route.ts і тест Vitest у tests/. Використовуй, коли просять новий ендпоінт, API-маршрут чи обробник HTTP-запиту. Не використовуй для змін сторінок, компонентів і стилів.»

---

## 2. Протокол тестування

### А. Позитивний тест (Trigger Positive)
* **Запит**: «Додай новий API-ендпоінт GET /api/version, який повертає { version: "1.0.0" }»
* **Очікувана поведінка**: Агент зчитує `SKILL.md`, створює схему `src/version.ts`, тест `tests/version.test.ts`, обробник `app/api/version/route.ts` та запускає скрипт валідації `node scripts/check-route.mjs version`.

| Інструмент | Модель | Чи спрацювала навичка | Доказ у журналі | Результат валідатора |
|---|---|---|---|---|
| **Codex CLI** | GPT-5.6-terra | Так | Читання `.claude/skills/add-api-route/SKILL.md`, запуск `check-route.mjs` у `.agent-log/codex.jsonl` | `OK` (код 0) |
| **Antigravity CLI / IDE** | Gemini 3.8 Flash | Так | Завантаження навички `add-api-route`, виконання процедури валідації у `.agent-log/antigravity.jsonl` | `OK` (код 0) |

---

### Б. Негативний тест (Trigger Negative)
* **Запит**: «Додай утиліту math-helpers у src/ з функцією clamp»
* **Очікувана поведінка**: Навичка `add-api-route` **не повинна** активуватися, оскільки задача стосується звичайної утиліти, а не API-ендпоінту.

| Інструмент | Модель | Чи уникнув виклику навички | Доказ у журналі | Коментар |
|---|---|---|---|---|
| **Codex CLI** | GPT-5.6-terra | Так | Відсутні звернення до `SKILL.md` та `check-route.mjs` | Агент не підтягнув зайвий контекст |
| **Antigravity CLI / IDE** | Gemini 3.8 Flash | Так | Відсутні виклики навички `add-api-route` | Маршрутизація за описом (description) спрацювала вірно |

---

## 3. Висновок

1. Навичка `add-api-route` демонструє **100% точність маршрутизації**: активується виключно при запитах на створення HTTP-обробників та ігнорується для інших завдань.
2. Процедура автоматичної синхронізації через `npm run sync-skills` забезпечує однакову доступність навички як для Claude/Codex екосистеми, так і для Antigravity.
