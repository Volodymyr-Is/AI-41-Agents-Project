# Впевнені помилки — Лабораторна 1

Спіймані впевнені помилки та галюцинації агентів кодування під час дослідження кодової бази, планування та реалізації задач.

| № | Інструмент і модель | Що стверджував / запропонував агент | У чому полягала помилка / небезпека | Як виявили (доказ) | Що зробили для виправлення |
|---|---|---|---|---|---|
| 1 | Codex CLI, GPT-5.6-terra | Пропонував створити маршрут у `pages/api/health.ts` або додати аргумент `request: Request` в сигнатуру `GET()` | У проєкті використовується Next.js App Router (`app/api/health/route.ts`), а тест `health.test.ts` викликає `GET()` без аргументів. | Перевірка плану до схвалення та сигнатури виклику в `tests/health.test.ts` | Уточнили вимогу в плані використовувати саме `app/api/health/route.ts` без параметрів. |
| 2 | Antigravity CLI / IDE, Gemini 3.7 Flash | При виконанні хука `PostToolUse` намагався знайти скрипт у `.agents/scripts/agent-log-hook.mjs` замість кореневого `scripts/` | Antigravity встановлює CWD хука в папку, де лежить `hooks.json` (тобто `.agents/`), через що відносний шлях без `../` створював дублікати файлів. | Поява небажаної папки `.agents/.agent-log/` та помилка хука | Виправили шлях у `.agents/hooks.json` на `../scripts/agent-log-hook.mjs` та додали нормалізацію кореня проєкту в скрипті. |
| 3 | Codex CLI / Antigravity | Стверджував, що для правильної валідації `timestamp` обов'язково потрібно імпортувати зовнішню бібліотеку `dayjs`/`date-fns` | Для повернення ISO 8601 та проходження схеми `z.iso.datetime()` достатньо нативного `new Date().toISOString()`, зайві залежності заборонені правилами проєкту. | Порівняння плану з вимогами `AGENTS.md` (заборона `npm install` без дозволу) | Відхилили встановлення пакетів, вказали використати нативний `toISOString()`. |

## Висновок

Режим плану (Plan Mode) та ретельна перевірка пропозицій до їх виконання дозволяють виявити архітектурні розбіжності та зайві дії ще до того, як вони потраплять у diff репозиторію.
